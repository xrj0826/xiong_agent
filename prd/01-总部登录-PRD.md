# 餐饮员工管理系统 V1.0 — 总部登录 PRD

| 项目 | 内容 |
|---|---|
| 文档编号 | AUTH-01 |
| 版本 | V1.0 |
| 状态 | 已确认基本范围；少量实现细节待定 |
| 使用对象 | 总部内部人员（同一个总部登录账号） |
| 关联模块 | 门店管理、员工管理、排班管理；后续考勤、绩效、薪资管理 |

## 1. 背景与目标

V1.0 仅供品牌总部内部使用。用户通过一个总部账号进入系统，对全部直营门店的人员及经营相关数据进行管理。不开发多用户组织、店长登录或细粒度权限体系。

**已确认：**
- 只设总部登录入口与总部账号；不开放店长、普通员工账号。
- 总部登录后可操作所有模块、查看所有门店数据。
- 支持账号密码登录、修改密码及退出登录。
- 不支持自行注册及角色权限配置。

## 2. 功能范围

| 编号 | 功能 | V1.0 范围 |
|---|---|---|
| AUTH-001 | 登录 | 输入账号和密码登录 |
| AUTH-002 | 登录态校验 | 未登录不能访问任何业务页面和业务接口 |
| AUTH-003 | 修改密码 | 已登录的用户修改本人密码 |
| AUTH-004 | 退出登录 | 主动结束当前登录会话 |
| AUTH-005 | 基础登录安全 | 密码安全存储、失败提示、会话过期处理 |

**不做：**账号注册、员工登录、店长登录、多账号管理、角色/菜单权限配置、扫码登录、短信登录、第三方单点登录、可视化操作审计平台。

## 3. 页面需求

### 3.1 登录页

- 页面元素：系统名称、登录账号输入框、登录密码输入框、登录按钮、错误提示区域。
- 登录成功后进入系统的默认业务页面（建议门店管理；最终以整体导航设计为准）。
- 账号或密码错误时统一提示“账号或密码错误”，不透露具体是哪一项错误。
- 账号、密码为空时不发起登录；输入密码以掩码展示。
- 页面无需“注册”“忘记密码”“切换角色”等入口。

### 3.2 个人设置

- 提供「修改密码」：原密码、新密码、确认新密码。
- 新密码与确认新密码不一致时阻止提交。
- 验证原密码后才允许修改；修改成功后重新登录。
- 提供「退出登录」操作。

## 4. 数据字段

| 对象 | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 总部账号 | 账号ID | 系统ID | 自动 | 系统内部唯一标识 |
| 总部账号 | 登录账号 | 字符串 | 是 | 初始化时配置的账号名称或手机号 |
| 总部账号 | 密码摘要 | 字符串 | 自动 | 服务端存储安全散列，不存明文 |
| 总部账号 | 账号状态 | 枚举 | 是 | 启用、停用；V1.0 无账号管理界面 |
| 总部账号 | 密码更新时间 | 时间 | 自动 | 支持安全处理及维护 |
| 登录会话 | 会话标识 | 系统生成 | 自动 | 对应已登录会话；不暴露凭证内部实现 |
| 登录会话 | 过期时间 | 时间 | 自动 | 超时后需重新登录 |

## 5. 业务规则与异常场景

1. **一个总部账号：** 初始化时配置一个可用总部账号；不可通过页面创建第二个账号。
2. **全量数据访问：** 登录后无需做门店级或岗位级权限分配；业务页面统一要求有效登录。
3. **安全存储：** 服务端使用适当的密码散列算法；不在日志、接口返回或前端持久化中保存密码明文。
4. **会话失效：** 主动退出、修改密码后、会话过期时均要求重新登录。
5. **未授权访问：** 未登录直接输入页面 URL 或调用业务接口时，不返回业务数据，跳转/提示登录。
6. **账号密码错误：** 登录失败但不建立会话；允许用户重新输入。
7. **系统异常：** 网络或服务器异常时显示可理解的失败提示，不误报为密码错误。
8. **初始账号维护：** V1.0 没有“忘记密码”自助流程，遗失密码通过受控的运维方式重置。

## 6. 验收标准

- [ ] 输入正确账号和密码，进入系统并能访问所有已上线的业务模块。
- [ ] 输入错误账号或密码，不能登录，显示统一失败提示。
- [ ] 空账号或空密码不能提交。
- [ ] 未登录时直接打开业务页面、调用业务接口，均无法获得业务数据。
- [ ] 修改密码时校验原密码、两次新密码一致性。
- [ ] 修改密码成功后原密码不能继续使用，要求重新登录。
- [ ] 退出登录后刷新或返回业务 URL 不可继续操作。
- [ ] 服务端未明文存储密码。

## 7. 待确认（不阻塞其他模块 PRD）

- 登录账号具体使用“手机号”还是“自定义账号名”。
- 会话有效期及是否支持保持登录。
- 新密码最小长度等具体安全策略。

> 以上待确认项不影响“仅总部单账号登录”的既定产品方案。
